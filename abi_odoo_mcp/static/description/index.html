🤖 ChatGPT (Native Custom MCP Server)
Web & Plus ▼ ▲

Connect ChatGPT directly to your live Odoo instance in 4 simple steps using ChatGPT's native Custom MCP Server feature:

1 Get Your Odoo Server URL & Access Token

In Odoo, navigate to MCP Server > Access Tokens, open your token, and click the "Share Connection" button. Copy the complete Server URL containing your secure token parameter.

2 In ChatGPT: Go to Plugins > Add custom MCP server

In the left sidebar of ChatGPT, select Plugins. In the top-right corner, click the "Add" menu and select "Add custom MCP server".

3 Configure Connection & Critical URL Requirements

In the modal, enter Name odoo-mcp, select Server URL, and paste your Server URL. Keep Authentication set to No authentication (since the token is securely embedded in the URL). Check "I understand and want to continue" and click "Create as a plugin".

⚠️ CRITICAL CONNECTION REQUIREMENTS:
  • MUST USE HTTPS (NOT HTTP): ChatGPT cloud servers strictly enforce secure connections and will reject plain http:// URLs. Make sure your Server URL starts with https://.
  • LIVE DOMAIN OR NGROK REQUIRED (NO localhost): OpenAI's cloud cannot access your private computer (e.g. localhost:8069 or 127.0.0.1).
    • Production Odoo: Use your live public domain with SSL (e.g. https://erp.yourcompany.com/mcp?token=...).
    • Local Development / Testing: Run an HTTPS tunnel such as ngrok http 8069 (or your custom port) and use the live ngrok URL (e.g. https://xxxx.ngrok-free.dev/mcp?token=...).
4 Mention @odoo-mcp & Chat Naturally with Your ERP

In your ChatGPT chat box, type @od and select @odoo-mcp. Your ChatGPT session is now directly connected to your Odoo ERP! Ask questions, inspect business metrics, review records, or request live spreadsheet dashboard previews.

🟠 Claude (Web, Desktop App & Claude Code)
Web & Desktop ▼ ▲

Connect Claude directly to your Odoo ERP in 3 clicks using Claude's native Custom Connectors:

1 Open Settings > Connectors > Add custom connector

In Claude (Web or Desktop App), open Settings. In the left menu under Customize, click Connectors. In the top-right corner, click + Add and select "Add custom connector".

2 Configure Connector Name & Live Server URL

In the modal, enter Name odoo-mcp and paste your Odoo Server URL with your token (copied from Odoo Access Tokens > Share Connection). Click Continue.

⚠️ CRITICAL CONNECTION REQUIREMENTS:
  • MUST USE HTTPS (NOT HTTP): Claude strictly requires secure SSL endpoints and will reject plain http:// URLs. Make sure your Server URL starts with https://.
  • LIVE DOMAIN OR NGROK REQUIRED (NO localhost): Claude runs in the cloud and cannot connect to your private computer (e.g. localhost:8069 or 127.0.0.1).
    • Production Odoo: Use your live public domain with SSL (e.g. https://erp.yourcompany.com/mcp?token=...).
    • Local Development / Testing: Run an HTTPS tunnel such as ngrok http 8069 (or your custom port) and use the live ngrok URL (e.g. https://xxxx.ngrok-free.dev/mcp?token=...).
3 Enable Connector in Chat & Start Interacting

In any Claude chat session, click the + menu next to the chat box, hover over Connectors, and make sure odoo-mcp is toggled ON. Claude can now query records, generate live spreadsheet dashboard previews, and audit your ERP!

🔵 Cursor IDE (.cursor/mcp.json — Direct HTTP)
Developer ▼ ▲

Cursor connects directly to your Odoo MCP server over HTTP without needing any bridge script:

1 Open Tools & MCP in Cursor

Press Ctrl + Shift + P (or Cmd + Shift + P on macOS), type "mcp", and select "Cursor: Tools & MCP" (or navigate to Settings > Tools & MCP / Customize).

2 Add New Custom MCP Server > Select Workspace

Under Connected, click "+ New MCP Server" (Add a Custom MCP Server). From the dropdown, select your workspace (e.g. odoo-mcp-main) to create or edit .cursor/mcp.json.

3 Paste JSON Configuration into .cursor/mcp.json

In your project's .cursor/mcp.json, paste the configuration snippet below. Copy your live Server URL directly from Odoo (via MCP Server > Access Tokens > Share Connection): 

{
  "mcpServers": {
    "odoo-mcp": {
      "url": "https://<your-odoo-domain-or-ngrok>/mcp?token=mcp_live_YOUR_TOKEN"
    }
  }
}
💡 Tip: The Server URL copied from Odoo automatically uses https:// for tunnels like ngrok and live domains!
4 Enable Source & Reload

In the Configure odoo-mcp modal, toggle the .cursor/mcp.json source ON (active) and click Done.

5 Verify Connection & Query Live ERP in Cursor Chat

Notice odoo-mcp now shows green with 32 tools and 2 resources enabled! In Cursor Chat (Ctrl + L), ask: "use my odoo-mcp, how many sale orders?" Cursor will immediately fetch live sales figures directly from your Odoo database.

🪐 Antigravity IDE (mcp_config.json)
IDE ▼ ▲

Antigravity IDE connects directly to your Odoo MCP server over HTTP via its native MCP configuration:

1 Open Manage MCP Servers in Antigravity

Press Ctrl + Shift + P (or Cmd + Shift + P on macOS), type "manage mcp", and select "Manage MCP servers".

2 Click "View raw config"

In the Manage MCP servers view, click the "View raw config" button in the top right to open your global mcp_config.json file.

3 Paste JSON Configuration into mcp_config.json

Under mcpServers, add the odoo-mcp server configuration block with the HTTPS Server URL copied directly from Odoo (via MCP Server > Access Tokens > Share Connection): 

{
  "mcpServers": {
    "odoo-mcp": {
      "url": "https://<your-odoo-domain-or-ngrok>/mcp?token=mcp_live_YOUR_TOKEN",
      "disabled": false
    }
  }
}
💡 Tip: The Server URL copied from Odoo automatically uses https:// for live domains and ngrok tunnels!
4 Click "Refresh" to Load All 32 Odoo Tools

Save mcp_config.json and switch back to the Manage MCP servers view. Click the "Refresh" button — Antigravity will instantly discover the server and register all 32 Odoo tools!

5 Verify Connection & Query Live ERP in Antigravity Chat

In the Antigravity Chat panel, ask: "use my mcp, how many sale order i have". Antigravity will invoke the Odoo MCP tools in real time and return live data directly from your database!

Enterprise Security & Control

How Is Your Company Data Protected?

Unlike external scripts that require dangerous admin credentials, Odoo MCP enforces Zero-Trust architecture natively inside Odoo.

🛡️ Native User Permissions

Every AI request runs strictly under the assigned Odoo user's security context (request.env(user=...)). The AI cannot see or modify any record that the user isn't allowed to access. Zero .sudo() bypasses.

⏱️ Active Rate Limiting

Prevent runaway AI loops with sliding-window rate limits (e.g. 120 req/min). If an AI client exceeds the limit, it receives a friendly cooldown without freezing your Odoo server.

🚫 Read-Only Mode & Safety Guards

Toggle Read-Only Mode in 1 click for pure analytical assistants. Built-in bulk safety guards prevent accidental mass deletions (>25 records).

📜 Complete Audit Logging

Every single AI prompt, tool execution, response latency, and token estimate is recorded in the dedicated mcp.audit.log view with pivot and graph analytics.

Frequently Asked Questions

Is this module 100% free and open source? ▼ ▲
Yes! This module is released under the LGPL-3 license for both Odoo Community and Odoo Enterprise. There are no hidden fees, paid tiers, or limits.
Do I need to install Python packages or Docker containers on my server? ▼ ▲
No. Odoo MCP Server has zero external Python dependencies. It uses standard Python libraries and pure Odoo ORM methods. You just install the module in Odoo and you are ready.
Can the AI accidentally delete or overwrite our important business data? ▼ ▲
No. You have total control: you can toggle Read-Only Mode so the AI cannot write anything, every operation runs with your user's specific access rights, and built-in bulk protection blocks any request attempting to modify or delete more than 25 records.
Which Odoo versions are supported? ▼ ▲
Odoo 18.0 (Community & Enterprise).
