# Odoo MCP Server (module)

Technical name: `abi_odoo_mcp`

This directory contains the **Odoo MCP Server** addon — a native **Model Context Protocol (MCP)** server for Odoo 17 and 18.

## Documentation

Full installation, client setup (Claude Desktop, Cursor), tool reference, security model, and FAQ:

**[../README.md](../README.md)** (repository root)

## Odoo Apps listing

- App name: **Odoo MCP Server**
- Store description: `static/description/index.html`
- Icon: `static/description/icon.png`

## Quick install

```bash
odoo-bin -d <your_database> -i abi_odoo_mcp
```

Then open **MCP Server** in the app switcher and create an access token.
